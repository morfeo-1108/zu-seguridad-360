# ZU360 — Módulo de Emergencias

## Estructura del Plan de Emergencias

```
1. INFORMACIÓN GENERAL
   - Datos de la empresa
   - Descripción de las instalaciones
   - Actividades y procesos con mayor riesgo

2. ANÁLISIS DE VULNERABILIDAD
   - Amenazas identificadas (sismo, incendio, explosión, etc.)
   - Nivel de vulnerabilidad: alta/media/baja
   - Capacidad de respuesta

3. ESTRUCTURA ORGANIZACIONAL DE EMERGENCIAS
   - Jefe de Brigada
   - Brigadistas por rol: contra incendio / primeros auxilios / evacuación / búsqueda y rescate
   - Brigada mínima: 1 por cada 20 trabajadores

4. PROCEDIMIENTOS DE RESPUESTA
   - Protocolo incendio
   - Protocolo sismo
   - Protocolo derrame de sustancias
   - Protocolo emergencia médica
   - Protocolo amenaza de bomba

5. SISTEMA DE ALARMAS Y COMUNICACIONES
   - Señal de alarma, significado y activación
   - Cadena de llamadas (quién llama a quién)
   - Números de emergencia: 123 / Bomberos / Cruz Roja / ARL

6. RUTAS DE EVACUACIÓN Y PUNTOS DE ENCUENTRO
   - Mapa de evacuación por piso/área
   - Puntos de encuentro identificados
   - Personas con movilidad reducida (plan especial)

7. RECURSOS PARA EMERGENCIAS
   - Inventario extintores: tipo, capacidad, ubicación, vigencia
   - Botiquines: ubicación, contenido, vigencia medicamentos
   - Camillas, desfibrilador (si aplica)
   - Kit de derrames (si aplica)
```

## Gestión de Simulacros

```
PRE-SIMULACRO:
□ Definir tipo (parcial / total / sorpresivo / avisado)
□ Fecha, hora y escenario hipotético
□ Roles asignados: observadores, coordinadores, evaluadores
□ Información previa al personal (si es avisado)

DURANTE:
□ Activación de alarma (cronometrar)
□ Evacuación (tiempo objetivo: < 3 min edificio 1 piso)
□ Conteo en punto de encuentro
□ Atención de heridos simulados (si aplica)
□ Coordinación con entidades externas (si aplica)

POST-SIMULACRO:
□ Tiempo total de evacuación
□ Personas que no evacuaron y causa
□ Fallas identificadas
□ Calificación general: Excelente / Bueno / Regular / Deficiente
□ Plan de mejora para próximo simulacro
```
