# ZU360 — Auditorías Internas SG-SST

## Ciclo PHVA — Estructura de Auditoría

### PLANEAR (25%)
```
1.1 Política y objetivos SST definidos y comunicados
1.2 Identificación de requisitos legales aplicables
1.3 Recursos asignados (humanos, financieros, técnicos)
1.4 Responsabilidades definidas y documentadas
1.5 Programa anual de trabajo con cronograma
```

### HACER (60%)
```
2.1 Gestión de peligros y riesgos (GTC-45 actualizada)
2.2 Gestión de amenazas y plan de emergencias
2.3 Evaluaciones médicas ocupacionales al día
2.4 Reporte e investigación de AT y EL
2.5 Medición y control de riesgos prioritarios
2.6 Capacitaciones ejecutadas según programa
2.7 COPASST funcionando (actas mensuales)
2.8 Gestión de contratistas con documentación
2.9 Inspecciones de seguridad realizadas
```

### VERIFICAR (5%)
```
3.1 Indicadores medidos y analizados (IF, IS, ILI)
3.2 Auditoría interna realizada al menos 1 vez/año
3.3 Revisión por la dirección documentada
```

### ACTUAR (10%)
```
4.1 No conformidades con plan de acción y cierre
4.2 Acciones preventivas y correctivas implementadas
4.3 Mejora continua documentada
```

## Escala de Calificación Res. 0312/2019

```
Ítem CUMPLE    = 100% del puntaje del ítem
Ítem PARCIAL   = 50% del puntaje del ítem
Ítem NO CUMPLE = 0%

TOTAL:
< 60%   → CRÍTICO        → Plan mejoramiento + notificar Min. Trabajo
60-85%  → MOD. ACEPTABLE → Plan mejoramiento 6 meses
> 85%   → ACEPTABLE      → Plan mejoramiento anual (mantenimiento)
```

## Informe de Auditoría — Estructura

```
1. Portada: empresa, NIT, período auditado, auditor, fecha
2. Alcance y criterios de auditoría
3. Metodología utilizada
4. Tabla de hallazgos:
   | # | Requisito | Evidencia encontrada | Calificación | Tipo |
   Tipo: Conformidad / No Conformidad / Observación / Oportunidad de mejora
5. Puntaje por ciclo PHVA y total
6. Semáforo de cumplimiento
7. Conclusiones del auditor
8. Plan de mejoramiento con responsables y fechas
9. Firmas: auditor + gerencia
```

## Archivos Generados
1. **Informe_Auditoria_SG-SST_[Empresa]_[Año].docx** — Informe completo
2. **Autoevaluacion_Res0312_[Empresa].xlsx** — Con puntajes y semáforo
3. **Plan_Mejoramiento_[Empresa].xlsx** — No conformidades con seguimiento
4. **Acta_Revision_Gerencia_[Empresa].docx** — Revisión por la dirección
